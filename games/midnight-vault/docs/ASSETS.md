# Midnight Vault: asset manifest

Generated by `node tools/asset-manifest.mjs`. Every asset is a separate file.

- **Painted sources:** the supplied artwork in `art/source/` (symbol sheet, logo, UI sheet, bank and vault backgrounds, concept boards and mockups). `python3 tools/import-painted.py` cuts it into `art/painted/<name>.png` and the UI pieces in `src/client/ui/img/`.
- **Vector sources:** editable SVG in `art/svg/`, generated from `tools/art/*.mjs` (letters A-10 with plates matching the painted tiles, reel border, reel panel, chain, clock, seals, particles). A painted source always takes priority.
- `npm run art` renders everything (painted first) into the runtime files.
- **Full-resolution render:** PNG in `art/render/` (regenerated, not committed).
- **Runtime:** WebP in `public/assets/`. The 14 symbols are also packed into one atlas (`public/assets/symbols.webp` + `symbols.json`, Pixi spritesheet format, 4x4 grid of 320 px cells).


No asset contains UI text, labels or watermarks; all game text is rendered by the DOM UI or Pixi text. The only lettering is the title wordmark in `logo`, set in Cinzel Decorative (SIL Open Font License), embedded into the SVG.

## Sound

All sound is synthesised at runtime with the Web Audio API (`src/client/audio.ts`): an ambient drone with a music-box motif, plus 19 effects (reel spin/stop, landings, relic, expansion, surge, wins, big win, vault door, chains, phantom, transformation, clock tick, clock strike, bonus entry/end, retrigger, keys). There are no sample files and no third-party audio. Music and effects have separate toggles, plus a master mute.
