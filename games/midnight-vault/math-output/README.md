# math-output

Generated by the math pipeline; contents other than this file are git-ignored (the bonus book file is over 100 MB).

- `npm run math:dev` writes `dev/` (20,000 natural books per mode), which the local mock RGS serves.
- `npm run math:publish` writes `publish/` (100,000 natural books per mode) and `public/math.json`.

Each folder holds the Stake Engine upload set (`index.json`, `books_<mode>.jsonl.zst`, `lookUpTable_<mode>_0.csv`) plus `stats.json`, `math.json` and `REPORT.md`. The published report is copied to `docs/MATH_REPORT.md`. Runs are reproducible from their seed (default 1313).
